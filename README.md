## CS Team Manager
Created as a hobby to pass time and enhance my understanding in Python. The program objective is to manage the points from competitive teams (inspired on *VRS*).<br>
<br>

## Features
- Create a new team
- Delete a team
- Edit a team manually *(points, victories, loses, name, etc)*
- Add/Remove points based on win and loss, including a streak feature. 
- When the program is closed, it generates an excel file containing the updated values permanently saved inside the *database.txt* file
